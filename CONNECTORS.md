# Connectors

## How tool references work

This plugin uses `~~category` as a placeholder for tools that vary by company. The Figma MCP is wired directly (it's the design tool this plugin is built around), but other external services are plug points — swap them out for whatever your client uses.

## Figma (wired — required)

The Figma MCP is configured in `.mcp.json`. To activate it:

1. Generate a Figma personal access token at https://www.figma.com/developers/api#access-tokens
2. Set the environment variable: `FIGMA_API_TOKEN=your_token_here`
3. The `system-setup`, `token-update`, and `system-audit` skills will automatically use it when a Figma URL or file is provided.

## Plug points — swap these per client

| Category | Default | Placeholder | Options |
|---|---|---|---|
| Asset / image library | Unsplash | `~~asset library` | Bynder, Canto, Brandfolder, any DAM |
| Font system | Google Fonts | `~~font system` | Adobe Fonts, Klim, Grilli Type, licensed foundry |
| Icon library | Heroicons | `~~icon library` | Tabler Icons, Material Symbols, Phosphor, Streamline, Lucide, custom SVG set |
| Data viz library | Recharts (web) / Victory Native (mobile) | `~~data viz` | D3.js, Chart.js, Highcharts, enterprise viz system |

## How to customize for a client

When deploying this plugin for a specific company, update the plugin configuration block (generated by the `system-setup` skill) with their chosen tools. The configuration block acts as the master reference — all skill outputs will draw from it.

```json
{
  "brand_tier": {
    "asset_library_override": "bynder",
    "font_system_override": "adobe-fonts",
    "icon_library_override": "phosphor"
  }
}
```

No code changes needed — just update the config block and the skills will adapt their recommendations and output accordingly.
