# Figma plugin generator

Instructions and patterns for generating Figma Plugin API scripts. Every script generated by the asset-generation skill must follow these patterns exactly.

---

## How to run a generated script

There are two ways a user can run the generated script in Figma — include both options in the output:

**Option 1 — Development plugin (recommended, persistent)**
1. In Figma desktop, open Menu → Plugins → Development → New Plugin
2. Choose "Run once" (no manifest UI needed)
3. Paste the generated script into `code.js`
4. Click "Run" — the plugin executes and closes

**Option 2 — Figma developer console (fastest for testing)**
1. Open Figma desktop
2. Open the developer console: Menu → Help → Toggle developer tools → Console tab
3. Paste the script and press Enter

## Variable lookup pattern

Always look up variables by name from the collection. Never hardcode variable IDs — they change between files.

```javascript
// ── VARIABLE UTILITIES ───────────────────────────────────────────

const COLLECTION_NAME = "[COLLECTION NAME]"; // e.g. "Token System"

async function getVariables() {
  const collections = await figma.variables.getLocalVariableCollectionsAsync();
  const collection = collections.find(c => c.name === COLLECTION_NAME);
  if (!collection) {
    figma.closePlugin(`Error: Variable collection "${COLLECTION_NAME}" not found. Run system-setup first.`);
    return null;
  }
  const allVars = await figma.variables.getLocalVariablesAsync();
  // Return a lookup map: { "color/brand/primary": Variable, ... }
  const varMap = {};
  for (const v of allVars) {
    if (collection.variableIds.includes(v.id)) {
      varMap[v.name] = v;
    }
  }
  return varMap;
}

// Bind a variable to a paint (fill or stroke)
function bindColorVar(node, property, variable) {
  if (!variable) return;
  const paint = { type: 'SOLID', color: { r: 1, g: 1, b: 1 }, opacity: 1 };
  const boundPaint = figma.variables.setBoundVariableForPaint(paint, 'color', variable);
  if (property === 'fills') node.fills = [boundPaint];
  if (property === 'strokes') node.strokes = [boundPaint];
}

// Bind a variable to a text fill
function bindTextColor(textNode, variable) {
  if (!variable) return;
  const paint = { type: 'SOLID', color: { r: 0, g: 0, b: 0 }, opacity: 1 };
  const boundPaint = figma.variables.setBoundVariableForPaint(paint, 'color', variable);
  textNode.fills = [boundPaint];
}

// Bind a variable to a numeric property (spacing, radius, etc.)
function bindNumericVar(node, property, variable) {
  if (!variable) return;
  try {
    node.setBoundVariable(property, variable);
  } catch (e) {
    // Property doesn't support variable binding — fall back to resolved value
    const modeId = Object.keys(variable.valuesByMode)[0];
    const val = variable.valuesByMode[modeId];
    if (typeof val === 'number') node[property] = val;
  }
}
```

## Frame and layout patterns

### Creating a mobile frame (375×812)

```javascript
function createMobileFrame(name) {
  const frame = figma.createFrame();
  frame.name = name;
  frame.resize(375, 812);
  frame.layoutMode = "VERTICAL";
  frame.primaryAxisSizingMode = "FIXED";
  frame.counterAxisSizingMode = "FIXED";
  frame.clipsContent = true;
  return frame;
}
```

### Creating a desktop frame (1440×900)

```javascript
function createDesktopFrame(name) {
  const frame = figma.createFrame();
  frame.name = name;
  frame.resize(1440, 900);
  frame.layoutMode = "HORIZONTAL";
  frame.primaryAxisSizingMode = "FIXED";
  frame.counterAxisSizingMode = "FIXED";
  frame.clipsContent = true;
  return frame;
}
```

### Auto-layout section with padding

```javascript
function createSection(name, direction = "VERTICAL", paddingH = 24, paddingV = 24, gap = 16) {
  const section = figma.createFrame();
  section.name = name;
  section.layoutMode = direction;
  section.primaryAxisSizingMode = "AUTO";
  section.counterAxisSizingMode = "FILL"; // stretch to parent width
  section.paddingLeft = paddingH;
  section.paddingRight = paddingH;
  section.paddingTop = paddingV;
  section.paddingBottom = paddingV;
  section.itemSpacing = gap;
  section.fills = []; // transparent by default
  return section;
}
```

### Binding padding and gap to spacing variables

```javascript
// After creating a section, bind its spacing to token variables:
function bindSectionSpacing(section, vars, paddingToken, gapToken) {
  if (vars[paddingToken]) {
    bindNumericVar(section, 'paddingLeft', vars[paddingToken]);
    bindNumericVar(section, 'paddingRight', vars[paddingToken]);
    bindNumericVar(section, 'paddingTop', vars[paddingToken]);
    bindNumericVar(section, 'paddingBottom', vars[paddingToken]);
  }
  if (vars[gapToken]) {
    bindNumericVar(section, 'itemSpacing', vars[gapToken]);
  }
}

// Example: bindSectionSpacing(section, vars, "spacing/6", "spacing/4");
```

## Text node patterns

Always load fonts before setting characters. Missing font loads are the most common plugin crash.

```javascript
async function createTextNode(name, content, fontFamily, fontStyle, size) {
  await figma.loadFontAsync({ family: fontFamily, style: fontStyle });
  const text = figma.createText();
  text.name = name;
  text.fontName = { family: fontFamily, style: fontStyle };
  text.fontSize = size;
  text.characters = content;
  text.layoutSizingHorizontal = "FILL"; // stretch to parent
  text.layoutSizingVertical = "HUG";
  return text;
}

// Example — binding font size to a typography token is not directly supported
// by Figma variable binding for text. Use the resolved px value instead:
// text.fontSize = 24; // resolved value from typography.size.3xl

// Bind text color to a variable:
// bindTextColor(text, vars["color/text/primary"]);
```

## Component assembly pattern

Build each component as a named frame, append children, then append to parent. Always set fills, strokes, and bindings after appending to parent.

```javascript
async function createButton(label, vars, fontFamily) {
  // Container
  const btn = figma.createFrame();
  btn.name = "Button / Primary";
  btn.layoutMode = "HORIZONTAL";
  btn.primaryAxisSizingMode = "HUG";
  btn.counterAxisSizingMode = "HUG";
  btn.primaryAxisAlignItems = "CENTER";
  btn.counterAxisAlignItems = "CENTER";
  btn.paddingLeft = 24;   // resolved from spacing.6
  btn.paddingRight = 24;
  btn.paddingTop = 12;    // resolved from spacing.3
  btn.paddingBottom = 12;
  btn.cornerRadius = 12;  // resolved from radius.lg

  // Label text
  const text = await createTextNode("Button / Label", label, fontFamily, "SemiBold", 16);
  btn.appendChild(text);

  // Bind fills after appending
  bindColorVar(btn, 'fills', vars["color/brand/primary"]);
  bindTextColor(text, vars["color/text/on-dark"]);

  // Bind radius (if variable binding is supported)
  bindNumericVar(btn, 'cornerRadius', vars["radius/lg"]);

  return btn;
}
```

## Input field pattern

```javascript
async function createInputField(label, placeholder, vars, fontFamily) {
  const group = createSection(`Input / ${label}`, "VERTICAL", 0, 0, 6);

  // Label
  const labelText = await createTextNode(`Input / ${label} / Label`, label, fontFamily, "Medium", 14);
  bindTextColor(labelText, vars["color/text/primary"]);
  group.appendChild(labelText);

  // Field container
  const field = figma.createFrame();
  field.name = `Input / ${label} / Field`;
  field.layoutMode = "HORIZONTAL";
  field.primaryAxisSizingMode = "FILL";
  field.counterAxisSizingMode = "HUG";
  field.paddingLeft = 16;
  field.paddingRight = 16;
  field.paddingTop = 12;
  field.paddingBottom = 12;
  field.cornerRadius = 8; // radius.md
  field.strokeWeight = 1;
  field.strokeAlign = "INSIDE";
  bindColorVar(field, 'fills', vars["color/surface/subtle"]);
  bindColorVar(field, 'strokes', vars["color/border/default"]);

  // Placeholder text
  const placeholderText = await createTextNode(
    `Input / ${label} / Placeholder`, placeholder, fontFamily, "Regular", 16
  );
  bindTextColor(placeholderText, vars["color/text/disabled"]);
  field.appendChild(placeholderText);
  group.appendChild(field);

  return group;
}
```

## Full script structure

Every generated script follows this structure:

```javascript
// [Header block — see boilerplate above]

(async () => {
  try {

    // 1. Load variables
    const vars = await getVariables();
    if (!vars) return;

    // 2. Define resolved fallback values (used when variable binding fails)
    const FONT_SANS = "[INJECT: resolved font family from typography.family.sans]";
    const FRAME_WIDTH = 375;  // or 1440 for desktop

    // 3. Load all fonts needed in this screen up front
    await figma.loadFontAsync({ family: FONT_SANS, style: "Regular" });
    await figma.loadFontAsync({ family: FONT_SANS, style: "Medium" });
    await figma.loadFontAsync({ family: FONT_SANS, style: "SemiBold" });
    await figma.loadFontAsync({ family: FONT_SANS, style: "Bold" });

    // 4. Create the main frame
    const screen = figma.createFrame();
    screen.name = "[INJECT: Template name — e.g. 'Checkout / Step 1 — Delivery']";
    screen.resize(FRAME_WIDTH, 812);
    screen.layoutMode = "VERTICAL";
    screen.primaryAxisSizingMode = "AUTO"; // hug: let content drive height
    screen.counterAxisSizingMode = "FIXED";
    screen.clipsContent = false;
    bindColorVar(screen, 'fills', vars["color/surface/default"]);

    // 5. Build sections and components
    // [INJECT: section and component assembly for the selected template]

    // 6. Place on canvas, center in viewport
    figma.currentPage.appendChild(screen);
    screen.x = figma.viewport.center.x - FRAME_WIDTH / 2;
    screen.y = figma.viewport.center.y - 400;
    figma.viewport.scrollAndZoomIntoView([screen]);

    figma.closePlugin(`✓ ${screen.name} created — ${screen.children.length} layers`);

  } catch (err) {
    figma.closePlugin("Error: " + err.message);
  }
})();
```

## Variable name conventions

When looking up variables, use these name paths (matching the token architecture):

| Token | Variable name in Figma |
|---|---|
| `color.surface.default` | `color/surface/default` |
| `color.brand.primary` | `color/brand/primary` |
| `color.text.primary` | `color/text/primary` |
| `color.text.secondary` | `color/text/secondary` |
| `color.text.on-dark` | `color/text/on-dark` |
| `color.border.default` | `color/border/default` |
| `color.border.focus` | `color/border/focus` |
| `color.semantic.danger` | `color/semantic/danger` |
| `color.surface.subtle` | `color/surface/subtle` |
| `spacing.4` | `spacing/4` |
| `spacing.6` | `spacing/6` |
| `radius.md` | `radius/md` |
| `radius.lg` | `radius/lg` |

Note: Figma uses `/` as the separator in variable names (it renders as nested groups in the panel). The token file uses `.` notation. Always translate `.` → `/` when building variable lookups.

## Figma variable binding support matrix

Not all Figma properties support variable binding via `setBoundVariable`. Use this matrix to decide when to bind vs. use resolved values:

| Property | Variable binding | Notes |
|---|---|---|
| Fill color | ✅ Yes | Via `setBoundVariableForPaint` |
| Stroke color | ✅ Yes | Via `setBoundVariableForPaint` |
| Text fill color | ✅ Yes | Via `setBoundVariableForPaint` on fills |
| Corner radius | ✅ Yes | `setBoundVariable('cornerRadius', var)` |
| Padding (all sides) | ✅ Yes | `setBoundVariable('paddingLeft', var)` etc. |
| Item spacing (gap) | ✅ Yes | `setBoundVariable('itemSpacing', var)` |
| Stroke weight | ✅ Yes | `setBoundVariable('strokeWeight', var)` |
| Font size | ❌ No | Set resolved px value directly |
| Font family | ❌ No | Use `loadFontAsync` + `fontName` |
| Line height | ❌ No | Set resolved value directly |
| Opacity | ❌ No | Set resolved value directly |
| Frame width/height | ❌ No | Use `resize()` with resolved value |
| Effect (shadow) | ⚠️ Partial | Shadow color bindable; blur/offset not |

When variable binding is not supported, always use the resolved token value — never a raw hardcoded value without noting the source token in a comment.
